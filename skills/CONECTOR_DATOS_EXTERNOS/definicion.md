# 📝 DEFINICIÓN DEL SKILL: CONECTOR_DATOS_EXTERNOS
Este módulo es un *Vertical Slice* de Antigravity OS encargado de la interoperabilidad con servicios de terceros (Trello).

## ✨ OBJETIVOS
- Proporcionar una interfaz unificada para la gestión de proyectos.
- Mantener la soberanía de los datos mediante el uso de variables de entorno locales.
- Implementar una estética futurista "Ámbar y Negro" para la visualización de datos.

## 🛠️ TECNOLOGÍAS
- Trello REST API v1.
- Hexagonal Architecture (Infrastructure Layer).
- Antigravity AuditLogger.
